# BIM OTC 平台余额结算说明

## 当前规则

OTC 买卖币只允许使用 BIM 平台余额结算：

```text
买方：冻结平台余额
卖方：冻结数字资产
成交：数字资产划给买方，平台余额划给卖方
取消或超时：两边资产原路解冻
```

支付宝、微信和银行卡默认关闭，不进入订单、不保存订单收款快照，也不允许通过提交旧的收款方式 ID 绕过。

## 后台配置

进入：

```text
OTC管理 -> OTC配置
```

支付方式开关：

- 平台余额：必须开启。
- 支付宝：当前关闭。
- 微信：当前关闭。
- 银行卡：当前关闭。

当前版本关闭平台余额时，后台会拒绝保存配置。

## 买币流程

1. 用户选择商家的卖币广告。
2. 服务端校验广告、限额、库存和双方钱包状态。
3. 冻结商家数字资产。
4. 扣减并托管用户平台余额。
5. 订单进入“平台托管待放币”。
6. 卖方确认后，数字资产进入买方平台资产账户，平台余额进入卖方钱包。

## 卖币流程

1. 用户选择商家的买币广告。
2. 冻结用户数字资产。
3. 扣减并托管商家平台余额。
4. 商家确认后，数字资产进入商家平台资产账户，平台余额进入用户钱包。

## 安全规则

- 创建订单在同一事务中冻结两边资产。
- 任意一边余额不足，整个订单创建回滚。
- 一个订单只有一条法币托管记录和一条数字资产托管记录。
- 重复请求通过 `request_id` 返回原订单，不重复冻结。
- 完成订单时两种托管记录必须都存在且状态有效。
- 取消和超时必须同时释放两类资产。
- 平台余额流水和数字资产账本均保留订单号。
- 用户不能交易自己商家的广告。
- 广告方向与用户买卖方向必须相反。
- 外部收款方式和外部链地址不参与站内 OTC 订单。

## 数据表

```text
mr_otc_order              OTC订单
mr_otc_fiat_hold          平台余额托管
mr_wallet_asset_hold      数字资产托管
mr_wallet_asset_account   数字资产账户
mr_transaction_statement  平台余额流水
mr_wallet_asset_ledger    数字资产账本
```

## 故障处理

发现余额不一致时先关闭 OTC，不要直接修改用户余额：

```text
OTC管理 -> OTC配置 -> 启用OTC -> 关闭
```

通过订单号同时核对 `mr_otc_fiat_hold` 和 `mr_wallet_asset_hold`，确认托管状态后再创建可审计的补偿记录。
