# BIM USDD 闪兑功能配置与使用说明

## 功能说明

闪兑用于将用户数字资产账户中的 `USDD` 可用余额兑换为 BIM 平台余额。

```text
USDD数字资产余额 -> 平台余额
```

这不是链上交易，也不会调用去中心化交易所。兑换汇率、手续费和限额由 BIM 后台配置，兑换完成后用户的 USDD 减少，平台余额增加。

## 后台位置

```text
钱包管理 -> 闪兑管理
```

首次部署时默认关闭。管理员需要检查下列参数：

- 兑换汇率：1 USDD 可以兑换多少平台余额。
- 手续费率：百分比，例如 `0.5` 表示 `0.5%`。
- 最低数量：单笔最少兑换多少 USDD。
- 单笔最高：单笔最多兑换多少 USDD。
- 每日限额：一个用户每天最多兑换多少 USDD。
- 报价秒数：报价有效期，允许范围 15 至 300 秒。
- 状态：关闭或开启。

示例：

```text
汇率：7.00000000
用户兑换：10 USDD
手续费率：0.5%
兑换总额：70.00
手续费：0.35
实际到账：69.65 平台余额
```

最终金额只由服务端计算。客户端显示值仅用于确认，不能修改结算结果。

## 客户端操作

```text
我的 -> 钱包 -> USDT资产页 -> USDD闪兑
```

1. 输入需要兑换的 USDD 数量。
2. 获取服务端短期报价。
3. 查看汇率、手续费和最终到账金额。
4. 输入六位支付密码。
5. 服务端完成原子结算。

## 资金安全规则

- 钱包被锁定时禁止报价和结算。
- USDD余额不足时禁止生成有效兑换结果。
- 报价过期后必须重新获取。
- 后台修改汇率或限额后，旧报价立即失效。
- 支付密码沿用现有三次错误锁定机制。
- 同一个 `request_id` 只能创建一个报价。
- 同一个报价只能结算一次。
- USDD扣款和平台余额入账位于同一个数据库事务。
- 结算同时生成数字资产账本和平台余额流水。
- 平台余额保留两位小数，USDD账本保留八位存储精度。

## 首次上线步骤

1. 部署数据库迁移。
2. 确认后台出现“闪兑管理”。
3. 保持状态关闭。
4. 给测试用户添加可审计的 USDD 测试余额。
5. 设置测试汇率和限额。
6. 开启闪兑并执行小额兑换。
7. 核对 USDD账本、平台余额和订单。
8. 重复提交同一报价，确认不会二次扣款。
9. 删除或冲正测试数据。
10. 审核运营汇率后正式开放。

## 数据表

```text
mr_otc_asset                USDD资产定义
mr_wallet_asset_account     用户USDD余额
mr_wallet_asset_journal     数字资产业务流水
mr_wallet_asset_entry       USDD扣款分录
mr_wallet_exchange_config   闪兑配置
mr_wallet_exchange_order    闪兑报价和订单
mr_user.money               用户平台余额
mr_transaction_statement    平台余额流水
```

## 紧急关闭

发现汇率错误、异常订单或账目不一致时：

```text
钱包管理 -> 闪兑管理 -> 状态 -> 关闭
```

关闭后新报价和未结算报价都不能继续执行。不要直接修改用户余额或删除订单，应通过审核后的补偿流水处理。
